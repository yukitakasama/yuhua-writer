## 如何采集

```bash
pnpm bench          # 自动采集环境信息与产物体积
```

自动采集会写出 `docs/benchmarks-generated.md`，包含环境信息、前端产物
体积、字体资产体积，以及**需要人工测量的指标清单与测量方法**。

内存类指标（M1–M8）与交互类指标（P1–P4、P7、P10、P11）依赖真实窗口
环境，必须人工测量后填入下方表格。

### P5：100 万字检索

P5 已由自动化集成测试覆盖，测试位于
`src-tauri/crates/yuhua-store/tests/index_integration.rs`：

- `search_on_million_chars_meets_p5_budget` —— 合成 100 章 × 1 万字
  （共 100 万字）的语料，索引后连续查询 5 次取中位数，断言 < 300 ms
- `search_result_count_is_correct_on_large_corpus` —— 校验召回数与
  直接扫描原文的结论一致
- `rebuild_fully_restores_a_large_index` —— 校验索引重建后检索结果不变

运行方式：

```bash
cargo test -p yuhua-store --release -- --nocapture
```

测试会打印实测耗时。**该测试使用内存数据库**，因此数字反映的是
索引与检索算法本身的成本，不含磁盘 IO。真实场景的端到端数字
仍需在完整应用上复测（计划书 T11.2）。
