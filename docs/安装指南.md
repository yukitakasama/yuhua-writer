# 安装指南

## 系统要求

| 项                                 | 要求                                                             |
| ---------------------------------- | ---------------------------------------------------------------- |
| 操作系统                           | Windows 10 1809 及以上（64 位）、macOS 10.15+、主流 Linux 发行版 |
| 内存                               | 建议 4 GB 以上（应用常驻目标 ≤ 150 MB）                          |
| 磁盘                               | 应用本体约 25 MB；数据占用取决于作品规模                         |
| **Microsoft Edge WebView2 运行时** | **Windows 必需**，见下                                           |

> **不支持 Windows 7 / 8**，也不承诺在精简版系统上的表现。

## Windows 上必须的前置组件：WebView2

羽化写作**不捆绑** WebView2 运行时，而是依赖系统已有的 Evergreen 运行时。
这样做的原因是安装包体积（安装包要留给内置中文字体），
代价是极少数机器首次启动时需要联网补装。

### 我怎么知道自己有没有

**绝大多数用户不需要做任何事：**

- Windows 11 **已预装**
- Windows 10 自 2021 年起随 Edge 浏览器一起广泛铺开

**如果缺失，应用不会静默崩溃**，而是弹出原生提示对话框，
说明缺少什么、并提供「打开官方下载页面」的入口。

### 手动安装

从微软官方页面下载并安装 **Evergreen Bootstrapper**：

<https://go.microsoft.com/fwlink/p/?LinkId=2124703>

WebView2 是微软随 Windows 免费提供的系统组件，**不是本软件的额外要求**。
许多现代 Windows 应用都依赖它。

## 安装

### Windows 安装包（NSIS）

1. 下载 `羽化写作_0.1.0-alpha.2_x64-setup.exe`
2. 运行安装程序。默认**仅为当前用户安装**，不需要管理员权限
3. 首次启动若是缺少 WebView2，按上节指引处理

### 便携版（ZIP）

解压后直接运行 `羽化写作.exe`。便携版会把配置写在
`%APPDATA%\YuhuaWriter`，工作区位置由你自己选择。

### macOS

第一阶段只提供**未签名**构建产物，需要手动解除隔离：

```bash
xattr -cr /Applications/羽化写作.app
```

签名与公证计划在第二阶段处理。

### Linux

提供 AppImage 与 deb 两种形式。AppImage：

```bash
chmod +x 羽化写作_0.1.0-alpha.2_amd64.AppImage
./羽化写作_0.1.0-alpha.2_amd64.AppImage
```

需要系统已安装 WebKitGTK 4.1。

## 从源码构建

### 前置

| 工具    | 版本   |
| ------- | ------ |
| Rust    | ≥ 1.77 |
| Node.js | ≥ 20   |
| pnpm    | ≥ 9    |

### 步骤

```bash
git clone https://github.com/yuhua-writer/yuhua-writer.git
cd yuhua-writer
pnpm install

pnpm icons            # 从 assets/icon.svg 派生全平台图标
pnpm fonts:fetch      # 获取字体源文件（需先在 fonts.lock.json 填入条目）
pnpm fonts:subset     # 子集化为 WOFF2

pnpm tauri:build      # 产出配置中的安装包
pnpm tauri:build -- --bundles nsis  # 仅构建 NSIS 安装包
```

Linux 上还需要这些系统库：

```bash
sudo apt-get install libwebkit2gtk-4.1-dev libappindicator3-dev \
  librsvg2-dev patchelf libgtk-3-dev
```

### 当前打包注意事项

`0.1.0-alpha.2` 的 NSIS 安装包已验证可构建。Windows MSI 目标要求预发布标识为纯数字，因此 `alpha.2` 会在 MSI 阶段被拒绝；构建 MSI 时请使用类似 `0.1.0-2` 的版本号，或只指定 `--bundles nsis`。

## 卸载

卸载应用不会删除你的工作区 —— **你的稿子在你选择的工作区文件夹里**，
与应用程序分离。若要彻底清理，还需要手动删除：

- 工作区文件夹（你自己选的目录）
- `%APPDATA%\YuhuaWriter`（配置、最近列表、索引缓存）

索引缓存删除后重建即可，不会丢任何内容。

## 常见问题

**Q：启动后是白屏**

A：几乎总是 WebView2 的问题。请确认已安装 Evergreen 运行时。

**Q：安装包比同类的写作软件小很多，是不是功能少**

A：不是。安装包小的原因是复用了系统 WebView 而不是打包一个 Chromium，
以及图标全部是内联 SVG 而不是字体文件。功能并不因此减少。

**Q：我的稿子存在哪里**

A：存在**你自己选择的工作区文件夹**里，是普通的 Markdown 文件。
你可以用任何编辑器打开，也可以随时用文件管理器备份或移动。

**Q：能不能多台设备同步**

A：把工作区文件夹放进任意云盘即可。详见
[云盘同步指南](./workspace-format.md)。

## 当前打包注意事项

Windows 默认使用 NSIS 多文件安装包，不再把 MSI 作为默认目标。NSIS 安装后保留正常的应用目录结构，便于后续扩展；不要将应用发布为单文件自解压 EXE。

### 目录型便携版

本机使用 7-Zip 生成目录型便携包：

```powershell
pnpm package:windows
```

命令会先构建 NSIS，然后在 `target/release/bundle/portable/` 生成 `YuhuaWriter_0.1.0-alpha.2_portable.7z` 和 `YuhuaWriter_0.1.0-alpha.2_portable.zip` 两种归档。解压后运行目录中的 `YuhuaWriter.exe`；`extensions/` 目录预留给未来的可选集成与资源。

ISO 不作为默认分发格式：它是磁盘镜像，不利于应用文件的增量更新、扩展和按文件替换。

### Inno Setup 安装包

本机已安装 Inno Setup 6，可使用以下命令生成多文件安装包：

`powershell
pnpm package:windows:inno
`

产物： arget/release/bundle/inno/YuhuaWriter_0.1.0-alpha.2_inno_setup.exe。这是安装程序文件，不是把应用打包成单文件运行程序；安装后应用目录和 extensions/ 目录仍然保留。
