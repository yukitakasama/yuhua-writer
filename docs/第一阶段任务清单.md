> 标记 **粗体** 的任务为 v1.2 新增或改动。里程碑已由 M0–M9 扩为 **M0–M11**

## 用法

- 每完成一项，把 `[ ]` 改为 `[x]`，并在「备注」列补充 PR 链接或关键结论
- **完成定义**：代码合并 + 测试通过 + 人工验收，三者缺一不可
- 本清单是执行面，范围与理由以计划文档为准；**不在此清单中的功能一律不做**
